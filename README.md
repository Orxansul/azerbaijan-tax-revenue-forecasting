## Overview

This project presents a reproducible Python-based analysis of Azerbaijan's annual tax revenue.

It combines historical trend analysis, forecasting model evaluation, statistical projections, and executive-level data visualization.

## Project Scope

- Historical period: 2006–2025
- Forecast period: 2026–2030
- Forecasting models evaluated: 8
- Historical prediction records: 320
- Evaluation metrics: MAE, RMSE, MAPE, WAPE
- Visual dashboard: 4 pages, 16 analytical panels

## Objectives

1. Analyze historical tax revenue trends.
2. Evaluate annual revenue changes.
3. Compare forecasting model performance.
4. Examine historical prediction errors.
5. Present alternative statistical forecasts through 2030.
6. Produce reproducible analytical outputs.

## Key Findings

Based on the evaluated model comparison:

- LinearTrend achieved the lowest MAE and RMSE.
- ARIMA (1,1,0) achieved the lowest MAPE.
- Forecasting model rankings differ across evaluation metrics.

These results illustrate why multiple accuracy measures are important when evaluating time-series forecasting models.

## Technologies

Python, Pandas, NumPy, Matplotlib, Jupyter Notebook, and statistical time-series analysis.

## Repository Contents

The repository contains:

- A reproducible Jupyter Notebook.
- Structured macroeconomic datasets.

- Forecasts for 2026–2030.

## Reproducibility

Install the required Python libraries using the provided requirements file.

Open the Jupyter Notebook and configure the input data paths if necessary.

Execute the notebook cells in sequence to reproduce the analytical outputs.

## Interpretation

Historical observations and future forecasts are distinct.

Forecasts for 2026–2030 are statistical estimates rather than official government budget projections.

Model performance is based on the evaluation methodology and historical prediction records included in the project.
